# Тест «Какой сексуальный сценарий управляет тобой?» — исходный код

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы: подтверждение возраста, стартовый экран, вопрос, форма контакта, результат |
| `style.css` | оформление: цвета, шрифты, отступы |
| `app.js` | вся логика: загрузка контента, показ вопросов, подсчёт результата, отправка заявки |
| `sheet.js` | чтение контента из Google-таблицы |
| `policy.html`, `consent.html`, `doc.js` | отдельные страницы политики и согласия, тексты берутся из таблицы |
| `content.js` | копия всех текстов и вопросов. Используется, если Google-таблица вдруг недоступна |
| `config.js` | настройки: адрес Google-таблицы и адрес функции для заявок |
| `checks.html` | страница самопроверки: прогоняет алгоритм на контрольных наборах ответов |
| `fonts/`, `fonts.css` | шрифты, лежат внутри сайта, чтобы страница не зависела от сторонних серверов |
| `функция-заявок/index.py` | код функции для Yandex Cloud, которая принимает и хранит заявки |

Чтобы посмотреть тест локально, откройте `index.html` двойным щелчком — он заработает на встроенной копии текстов из `content.js`.
Чтобы посмотреть проверку алгоритма, откройте `checks.html`.

## Где проверить алгоритм

Всё в файле `app.js`:

- функция `computeResult` — подсчёт: коэффициент каждого сценария, подтверждение, отбор результатов;
- функция `pickVariant` — выбор варианта для сценария «Оргазм как экзамен»;
- функция `resultLabels` — как результат называется на странице;
- функция `resultCodes` — что из результата уходит в заявку: только код сценария.

Правила, заданные в `Настройках` таблицы: сильный ответ — от 4, подтверждение — минимум 2 сильных ответа,
порог близости — 0,5, максимум результатов — 3. Вопросы со значением «Нет» в столбце «Участвует в расчёте»
(28–30) в подсчёт не попадают.

Порядок отбора: считается средний балл по каждому сценарию только среди подтверждённых → берётся лидер →
к нему добавляются подтверждённые сценарии, отстающие не больше чем на 0,5 → остаётся не больше трёх,
при равенстве баллов порядок берётся из столбца «Порядок» листа «Сценарии». Если не подтверждён ни один
сценарий, показывается нейтральный результат.

## Подтверждение возраста

Тест открывается только после подтверждения 18+. Ответ на этот вопрос нигде не сохраняется:
ни в базе, ни в браузере — при новом открытии страницы вопрос задаётся снова.
Если выбрано «Нет», кнопки исчезают и к тесту перейти нельзя.
Тексты этого экрана — ключи `age.*` на листе «Тексты».

## Что происходит с персональными данными

Ответы на вопросы хранятся только в памяти браузера, пока человек проходит тест, и нигде не сохраняются.

В заявку отправляются ровно четыре значения — это видно в функции `submitLead` в `app.js`:

```js
{
  date,                 // дата и время
  name,                 // имя из формы
  channel,              // выбранный способ связи
  contact,              // контакт из формы
  scenarios: [...],     // коды сценариев, например ["1", "2.3"]; "0" — нейтральный результат
  consent: true         // подтверждение согласия
}
```

Ответы на отдельные вопросы в этот набор не входят.

Названия сценариев в заявку не попадают — уходит только код из столбца «Код» листов «Сценарии»
и «Варианты» вашей таблицы. В выгрузке заявок вы увидите, например, `1; 2.3`, а не названия.
Расшифровка кодов есть в вашей таблице и на странице `checks.html` — она нигде не хранится
вместе с заявками. Функция хранилища отказывает в приёме, если вместо кода прислали текст.

На стороне хранилища (`функция-заявок/index.py`) принимаются и записываются те же поля: дата, имя,
способ связи, контакт и итоговые сценарии. Функция отказывает в приёме, если нет подтверждения согласия.
Выгрузка заявок и удаление заявки работают только с секретным ключом, который знаете только вы.

Пока адрес функции в `config.js` пустой — это значит, что заявки никуда не отправляются.
Хранилище подключается на втором этапе, вместе с вашими аккаунтами.
